# bmm.quest

Static archive of the bmm.quest WordPress site (BMM, the Flipside agent-application and event pages), captured on 2026-10-23 and retired to static hosting.

It was captured with wget, cleaned of dynamic WordPress features, links made relative, and verified. The site lives in `docs/`; see `DEPLOY.md` for publishing.

Visible changes from the original:
- The contact forms on `/contact/` and `/bmm-agent-application/` were replaced with a link to the main contact form at https://wegeekout.com/contact-me/.
- Search, comment forms, login/meta links and feeds were removed.
